# AdventureWorks-Sales-Analysis - $123M Revenue Project

## Project Overview
End-to-end data analysis of Microsoft's AdventureWorks database. Connected to SQL Server, processed 31,465 sales records, and extracted key business insights using Python.

## Key Results
- **Total Revenue:** $123,216,786.12
- **Peak Sales Year:** 2013 with $48.9M
- **Top Customer:** Roger Harui - $57,442
- **Top Product:** Mountain-200 Black, 38 - $4.4M
- **Records Analyzed:** 31,565 orders

## Tech Stack
`Python` `Pandas` `SQL Server` `PyODBC` `Matplotlib` `Jupyter` `Data Visualization`

## Business Impact
Identified high-value customers and top-selling products to guide inventory and marketing strategy for a $123M business.
